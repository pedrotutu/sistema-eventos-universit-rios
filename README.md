# Sistema de Eventos Universitários

Este é o front-end de um site desenvolvido para eventos universitários

## Link do Projeto Publicado
  [https://pedrotutu.github.io/sistema-eventos-universitarios/](https://pedrotutu.github.io/sistema-eventos-universitarios/)
## Tecnologias Utilizadas
 **HTML** 
 **CSS**

## Funcionalidades
* **index.html:** Apresentação do portal e de eventos apresentados.
* **programacao.html:** Tabela com horários e os locais (rowspan e colspan).
* **inscricao.html:** Formulário que simulação uma inscrição em eventos.
